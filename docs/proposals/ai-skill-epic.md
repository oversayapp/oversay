# Proposal: the epic rewritten, AI notes from any chat

Status: **agreed** by John, 2026-10-21 (design A; the recommendations below). The epic and its tasks were rewritten to match on GitHub the same day.

Design: the AI skill concepts mockup, in `oversayapp/design`. Decisions: ADR 0031 (the skill writes notes), 0032 (`oversay://` links), 0033 (the app installs the skill, nothing hosted), 0034 (the app watches its folders). All accepted 2026-10-21.

## Why rewrite it

The first plan was written before quick notes (ADR 0026), quick talks (ADR 0027) and Get ready (ADR 0019). It aimed at projects, a public install source and a "Help › Get the Oversay skill" dialog. Since then:

- the everyday ask is a **note** ("create me a note for my meeting with X");
- **nothing may be public** (ADR 0030), which rules out `npx skills add <public source>` and a mirror;
- John wants the skill to **open Oversay, show the note and start the overlays**, which the first plan ruled out (decision D6).

## Outcome (new)

In Claude Code, Codex, Claude desktop or Cowork, and ChatGPT, a person installs one Oversay skill **from inside Oversay** and asks "create me a note for my meeting with X" or "add this Markdown to my standup note". The note is then in Oversay's Quick notes, whether or not Oversay was open. In apps that can run a command, "open it" and "show it" open the note or put it on screen. In chats that can't reach the computer, the person pastes or drops the result into Oversay. The skill's format rules come from the app's code, so the two can't disagree.

## What each AI app can do (2026-10-21)

| App | Skill gets in by | Writes the note itself | Opens Oversay |
| - | - | - | - |
| Claude Code | copy to `~/.claude/skills/oversay` | yes | yes |
| Codex (CLI, IDE, Codex in the ChatGPT app) | copy to `~/.agents/skills/oversay` (check: `~/.codex/skills`) | yes | yes |
| Cowork | plugin zip uploaded at Customize › Plugins | only into a folder the task is allowed to work in | unverified |
| Claude chat (web, desktop, mobile) | same plugin, or a skill zip | no: it gives a file to download | no |
| ChatGPT Work (desktop) | skills in plugins; local files "when enabled" | unverified | unverified |
| ChatGPT Chat (web, desktop) | personal skills on some plans | no; local tools don't reach Chat (openai/codex#38162) | no |

The sources are listed on the design page's first screen. Honest summary: **ChatGPT Chat can't put a file on this computer.** Paste as note is the route there. The desktop app's Codex view is the full route.

## Tasks (proposed order)

Each task is a sub-issue of the epic. "Was" says which old task it replaces.

1. **Agree the design and ADRs** (this PR). Design A is chosen (John, 2026-10-21). John answers the questions below; ADRs 0031–0034 become accepted or are changed.
2. **The skill, notes only.** *Reshaped from the old plan.*
   - Contents: `skills/oversay/` with `SKILL.md`, `references/note-format.md` (part generated by `make skills`), examples, and the README with the install steps.
   - The skill can: make a note, add to a note, list notes, find one by name.
   - Tests: the examples parse to the expected topics through `lib/notes/format.ts`; a shared fixture checks that names become files as `folder_name` does; `make check` fails when the generated part is stale.
   - Hands-on: in Claude Code, a skill copied by hand makes a note that Oversay lists.
3. **Oversay notices new and changed files** (ADR 0034). *New; takes the note part of the old "project changed outside Oversay" task.*
   - Watches Quick notes and Quick talks; lists refresh; New on files not yet opened; the banner.
   - An open note reloads; Keep both / Use theirs when typing is waiting.
   - Tested with a pure function deciding the outcome. Screenshots via `make shots`.
4. **`oversay://` links** (ADR 0032). *New; replaces D6.*
   - Deep-link plugin; single instance on Windows; the five links; the ask-once dialog and its setting; refused during a session; logged without content.
   - The skill learns "open it" and "show it".
   - Hands-on with a built app on a Mac and on Windows.
5. **The AI page and installing from the app** (ADR 0033, design A, chosen). *Was the old AI page task, with the install half of the old chat-apps task.*
   - The skill is bundled in the app; the page finds Claude Code and Codex; Install, Update, Remove; `oversay-local.json`; Try it watches for the first note.
   - Entry points: the Home card and the empty Notes list.
   - A pure function maps (target, folder state, bundled version) to the row's state.
6. **Claude desktop and Cowork.** *Was part of the old chat-apps task.*
   - Save plugin… builds the plugin zip.
   - Hands-on: upload at Customize › Plugins; ask in Claude chat (expect a download); ask in Cowork with `Documents/Oversay` allowed (expect a note, record whether `open` works); the plugin synced into Claude Code next to the copied skill.
7. **ChatGPT, and notes from any chat.** *Was part of the old chat-apps task.*
   - **Drop a note file** anywhere on the window (design `#drop/…`).
     - Uses Tauri's window drop event, which gives the file's path (HTML5 drop doesn't).
     - Each `.md` is **copied** into Quick notes; the original, say in Downloads, stays where it is.
     - A taken name gets " 2", and Undo moves the copy to the Trash.
     - Other files are named and left out before the drop.
     - A `.oversay.json` opens as Open file… does.
     - Refused during a session.
   - **Paste as note** (⌘⇧V on Notes): makes a note from Markdown on the clipboard.
   - Copy instructions; Save skill zip.
   - Hands-on in ChatGPT Chat, Work and the Codex view, results recorded either way.
8. **Quick talks in the skill.**
   - A schema generated from `schema.ts` and a check that the skill runs (bundled script or `Oversay --check`; John's call).
   - "Make a 10-minute stand-up talk"; `oversay://talks/<name>/ready`.
9. **Prompt fixtures and the hands-on checklist.** *Was the old fixtures task.* As before, for notes and quick talks; one row per app.

## Decided (John, 2026-10-21: "go with your recommendations")

1. **Install design:** A, the AI page, entered from Home and the empty Notes list.
2. **Scope:** notes first, then quick talks; projects in a later epic.
3. **Links** open and show a note, and open a talk's Get ready page. They never go straight to Ready and never start the clock. The first show asks once.
4. **Claude Code** gets the copy Oversay installs. The plugin is for the Claude app (chat and Cowork). The README says to turn the synced plugin off in Claude Code when both are there.
5. **ChatGPT plan:** not known. Task 7 records what John's plan allows.
6. **Uploading the plugin to your own Claude account** is not "public" in ADR 0030's sense.
7. **Quick talk checks:** the app's own binary, `Oversay --check`. No Node needed.
8. **Gemini** is dropped from this epic.
